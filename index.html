      Make this your first screen

      1. Chrome startup: open chrome://settings/onStartup, choose "Open a specific page or set of pages", and add this page's address. Don't use "Continue where you left off", because it reopens yesterday's tabs.
      2. Every new tab: install the free "New Tab Redirect" extension and set this page as its URL.
      3. Install as an app: Chrome menu → Cast, save, and share → Install page as app.
      4. Open at Windows login: press Win+R, type shell:startup, and drag the First Light app shortcut into that folder.
      5. Block the pull: install "LeechBlock NG". Block youtube.com and netflix.com during your peak window, but allow 20 minutes per hour. That's your earned watch time. Set the blocked-page redirect to this app and protect its settings with a random access code.
      6. Keep tutorials, lose the rabbit hole: install "Unhook" to hide YouTube's recommendations and Shorts.
